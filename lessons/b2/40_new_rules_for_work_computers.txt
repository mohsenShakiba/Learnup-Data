New Rules for Work Computers
A: Have you managed to change your computer password yet? Mine keeps saying my new choice isn't strong enough.
B: Yes. I used the password manager that IT installed. It created a long combination of letters and numbers for me.
A: That sounds complicated. How am I supposed to remember it?
B: It saves it for you. I'll show you. Did something happen to make IT change the rules?
A: Yes, someone in the main office entered their password on a fake website. They still don't know whether anyone saw the customer files.
B: The message said the investigation's still open. What about this second part of the instructions?
A: About using our phones? I haven't read that far yet.
B: Yes. We have to enable an extra security check. It sends us a text with a number to enter when we sign in. Mine arrived almost instantly when I tried it.
A: So I enter that number as well as my password?
B: Right. There are new rules on saving files too. You can't copy customer records onto your own hard disk any more.
A: I still have an old computer at home with work files on it. The little receiver for its mouse has gone missing. Should I bring it in anyway?
B: Yes, and any discs that went with it. IT asked for both. They can take the files off them safely.
A: I'll bring the whole box tomorrow. Where should I save the files for our virtual meeting today?
B: In the shared space on the work network. Let's set up your new password first. Then we can try opening a file together.

Vocabulary: combination, complicated, disc, disk, enable, install, investigation, password, receiver, virtual
