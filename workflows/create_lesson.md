# Generating a lesson

Take about 10-20 vocabs from a1.csv in sentences folder.
pick vocabs that have a relation to each other as much as possible, like related to work, related to school, related to family and etc.
for each picked vocab if there are opposites or strongly related vocabs, pick them too. like for "cold", pick "hot" too, or for "left" pick "right" too.
put picked vocabs in a file called lesson_{number}.txt.
create sentences for the vocabs:
- if more than one vocab can be used in a sentence, use more than one
- if one vocab has been used in another sentence, it doesn't need a designated sentece but it's ok to be used in another sentence.
- the sentences should be easy, natural and not forced.
remove the used vocabs from a1.csv in the sentences folder.
